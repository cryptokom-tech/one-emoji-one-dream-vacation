Entry for the [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty on make.fun: send exactly one emoji, the one that most makes a stranger want to book the trip.

## The entry

🌋 — U+1F30B VOLCANO.

A volcano at dawn: the dream trip of a sunrise hike up a faraway peak, one
particular journey rather than any holiday. It reads as a postcard at a
glance — a place, not a moment or an activity — and it is a fresh pick next
to the field's crowded islands, Fujis and sunrises. Universally readable
since Unicode 6.0, clear at any size.

Chosen over the alternatives after local pairwise judging by the published
judge brief: 🏝️ and 🗻 are the field's most-entered picks and read generic;
🌅 is a moment, not a place; 🏄, 🐢, 🦩 and 🤿 name an activity or an animal
rather than the destination itself; 🏯 is specific but reads more like
sightseeing than a dream trip. The volcano wins on the brief's first
criterion — it plainly names a dream vacation, a faraway place — and stays
vivid, specific and surprising through the rest.

## How to run

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes exactly one emoji — one
Unicode character, four UTF-8 bytes, no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), and self-checks that the
file holds exactly that one character.
